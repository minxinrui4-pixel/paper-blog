# 纸间 · Vue 3 个人博客管理网站

## 个性化设置（新增）

- 在侧栏选择「个性化设置」，或点击作者头像，进入 `/settings`。
- 作者资料支持修改名字、上传头像、修改简介和所在地。图片支持 JPG、PNG、WebP，自动裁剪头像并压缩。
- 分类支持新增和改名，空分类也会保留。改名同步更新相关文章和首页草稿；导航、筛选及编辑器共用同一份分类列表。
- 背景提供星海流光、晨间极光、素色纸间和自定义图片；设置页提供预览，点击「保存设置」后应用。首次使用默认深色，也可通过侧栏切换深浅模式。
- GitHub 和 ChatGPT 图标在新窗口打开链接；默认分别为 `https://github.com/` 与 `https://chatgpt.com/`，可在设置页修改 HTTPS 地址。
- 作者和背景设置保存在 `paper-blog-settings-v1`；分类保存在 `paper-blog-categories-v1`。原有文章和附件的存储方式不变。
- 新增 `src/views/Settings.vue`、`src/lib/settings.js`、`src/components/SocialLinks.vue` 和 `src/appearance.css`。写作区可在首页展开，未发布内容仍自动保存为草稿。

背景素材：`src/assets/blowfish-background.svg` 来自 [Blowfish 官网](https://blowfish.page/zh-cn/) 的[公开背景](https://blowfish.page/images/v3/site-background.svg)，已下载到项目本地，不依赖外部图片服务。页面为本项目 Vue 实现。

一个中等难度的前端框架课程设计。参考 Stack 的侧栏与卡片布局，以“首页直接写文章、详情直接编辑”为核心流程，使用 Vue 3 重新实现。无需后端、账号、数据库服务器或文件管理页面。

## 启动与构建

需要 Node.js 20.19+ 或 22.12+，建议使用 Node.js 22 LTS。

```bash
npm install
npm run dev
```

打开终端打印的本地地址（默认 http://127.0.0.1:5173）。请通过 HTTP 服务访问，不要双击 index.html。

```bash
npm test          # 存储、安全过滤、搜索及分页测试
npm run build    # 构建到 dist
npm run preview  # 本地预览构建结果
```

路由使用 Hash 模式，部署 dist 到静态主机即可，不需要配置服务端路由回退。

基础版功能为中等难度；富文本、本地文件存储与异常处理是拓展项，适合答辩展示异步数据流。界面中的封面插画由 CSS 绘制，无需外部图片服务。字体优先使用在线 Noto 字体，离线时回退系统中文字体，功能不受影响。

## 功能点

- 首页直接显示标题、正文、分类与标签输入，支持发布和自动保存草稿。
- 卡片文章列表、每页 6 篇、详情阅读，按分类和标签组合筛选，搜索标题、摘要和正文。
- 详情页直接编辑与删除，编辑取消及未保存离开提示，管理页集中操作。
- 本地上传图片、正文插图、图片预览、封面设置、附件下载；单个文件限制为 10 MB。
- 深浅主题、响应式桌面/手机布局、本地阅读次数统计。
- 初次使用提供 7 篇中文示例；删除全部文章后保持空状态。
- 保存失败保留内容，正文清理脚本、事件属性与危险链接。

本项目为**本地作者模式**。当前浏览器中的访问者都能编辑，不提供服务端鉴权。阅读统计为当前浏览器数据，每篇文章每次浏览器会话首次访问计一次；示例文章自带演示基数。新文章从 0 开始。

## 组件与数据结构

```text
src/
  App.vue                 侧栏、个人资料、主题及页面布局
  components/
    Editor.vue            首页与编辑页共享的富文本编辑器
    PostCard.vue          文章卡片
    ArticleBody.vue       安全正文与本地图片恢复
    AssetImage.vue        本地封面与图片预览
    Art.vue / Icon.vue    CSS 插画及图标
  views/
    Home.vue              写作、列表、搜索、筛选和分页
    Detail.vue            文章阅读、附件下载、直接编辑与删除
    Edit.vue              编辑已有文章
    Manage.vue            文章管理
  lib/
    store.js              文章/草稿服务、阅读统计、引用清理
    assets.js             IndexedDB 附件服务与临时 URL 管理
    content.js            安全过滤、文本提取、筛选分页
    seed.js               首次初始化示例
    blog.test.js          核心业务测试
```

文章包含 `id/title/html/summary/category/tags/coverId/attachments/createdAt/updatedAt/views`，示例额外包含 CSS 插画名称 `art`。附件元数据包含 `id/name/type/size`。

`paper-blog-v1` 保存文章数组；`paper-blog-draft-v1` 保存首页未发布草稿；`paper-theme` 保存主题。IndexedDB 数据库 `paper-blog-assets` 的 `files` 对象仓库保存附件元数据和 Blob。正文使用 `data-asset-id` 引用图片，不保存临时 blob URL；页面渲染时从数据库恢复。

上传时先完成文件存储，发布或保存时再同步提交文章元数据。文件只在文章、草稿及当前编辑器均不再引用时清理。文件更换与删除属于编辑内容，取消时不会改变原文章。已上传但从未发布的文件可能在下次清理时回收。

存储容量由浏览器决定，清除站点数据、隐私模式结束或更换域名/端口/浏览器可能使数据不可用。10 MB 是每个文件的限制，并非总容量保证。请使用同一个访问地址演示；此版本不包含跨设备同步或旧项目数据迁移。

## 答辩演示建议

1. 展示首页布局及手机适配，说明 Vue 组件与语义标签的对应关系。
2. 直接在首页输入标题和正文，使用加粗、标题、列表，填写分类和标签。
3. 上传图片设为封面，再附加一个小文件；刷新验证草稿恢复后发布。
4. 进入详情，展示图片和文件下载，点击“编辑文章”修改并保存。
5. 尝试取消编辑和带未保存内容离开，再展示删除确认。
6. 演示组合筛选、搜索、分页、主题切换、阅读次数去重。
7. 刷新验证文章与附件仍在，运行测试和生产构建，解释两类存储各自的职责。

## 验收清单

- [ ] 首页发布后文章置顶，输入区清空，刷新后仍存在。
- [ ] 草稿标题、正文、标签、封面与附件刷新后恢复。
- [ ] 详情编辑保存成功；取消编辑不影响原文；删除确认有效。
- [ ] 图片插入、封面更换、附件下载、刷新恢复、超过 10 MB 提示有效。
- [ ] 搜索与分类标签可叠加，筛选后回到第一页，零结果有提示。
- [ ] 手机单列无横向溢出，主题刷新后保留，非法地址显示缺失提示。
- [ ] 本地存储失败时保留编辑内容；删除全部文章后刷新仍为空。
